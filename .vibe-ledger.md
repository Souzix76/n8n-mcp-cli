## Plan-Killer #2: Glama/MCP Registry manifest schema — ✅ RESOLVED

**MCP Registry uses `server.json` with schema:** `https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json`

**Required fields (ServerDetail):**
- `name` (reverse-DNS: `namespace/server`) — REQUIRED
- `description` (1-100 chars) — REQUIRED
- `version` (semver) — REQUIRED
- `packages[]` — at least one package with:
  - `registryType` (npm/pypi/oci/nuget/mcpb) — REQUIRED
  - `identifier` (package name or URL) — REQUIRED
  - `transport` (stdio/streamable-http/sse) — REQUIRED
  - `version` (exact semver) — REQUIRED
  - `environmentVariables[]` (optional)
  - `runtimeHint` (npx/uvx/docker/etc) — optional
  - `runtimeArguments[]` — optional

**Optional fields:**
- `title` (display name)
- `icons[]` (png/jpeg/svg/webp)
- `repository` (url, branch, directory)
- `websiteUrl` (homepage/docs)
- `_meta` (publisher-provided metadata)
- `remotes[]` (for remote transports)

**Ruling:** Plan-Killer #2 RESOLVED — Schema is well-defined, v2 is npm package with stdio transport, all required fields map directly.
